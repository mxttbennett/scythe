# Searchable Project and Task Picker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make project and task assignment in Add time entry fast to search and fully keyboard-operable.

**Architecture:** AddEntryForm continues to own the selected project and task. A shared searchable popover component renders the Project and Task choices, using the existing ordered active assignment lists as its only source of results. A small pure filter function supplies case- and accent-insensitive multi-word matching and gets focused unit coverage.

**Tech Stack:** Swift 6, SwiftUI, Testing, XcodeGen.
